# Marten Weijer

Static personal website for GitHub Pages. No JavaScript, dependencies, or build step.

- Edit `index.html` to update the biography, research, education, experience, or certifications.
- Edit `styles.css` to change the layout and appearance.
- The portrait and locally hosted fonts are in `assets/`.
- Keep `cv.pdf`, `gas-consumption.pdf`, and `missing-middle.pdf` alongside `index.html`.

Open `index.html` directly in a browser, or preview with:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.
